# GoldenDict 取词精简原型

这是用于验证内存和取词行为的实验版本。它没有修改或替换已安装的 GoldenDict-ng 和 SnapTra Translator。

## 使用

打开 `dist/GoldenDictLite.app`。在设置中选择按住取词的修饰键，启用 GoldenDict 集成和划词查询，点击划词快捷键按钮后按下所需组合键。根据需要开启复制到剪贴板，并选择识别语言。设置中还提供登录启动、菜单栏图标及样式、Dock 图标、界面语言，以及显示 OCR 捕获区域的开关。点击权限按钮，在 macOS 系统设置中为这个精简应用授权辅助功能和屏幕录制。权限更改后可能需要退出并重新打开应用。启动并保留 GoldenDict-ng。

为避免快捷键冲突，测试时应先暂停或退出 SnapTra。鼠标取词时按住所选修饰键并将鼠标移到单词上；划词查询则先选中文字，再按配置的组合键。

## 当前验证范围与限制

源码已编译，应用包已完成临时签名，启动命令已成功，进程曾出现。当前环境无法读取应用窗口，因此设置（包括登录启动和图标样式）、权限、截图、OCR、划词和 GoldenDict 小窗的完整链路尚未验证，也未验证登录自启动或将组件打包进 GoldenDict。此版本尚不能视为正式替代版。

OCR 的识别区域和分词功能参考原 SnapTra 代码，但精简版的取词调度和截图实现不完全相同。划词能否读取取决于目标应用是否暴露辅助功能文本。快捷键使用被动系统事件监听，可能同时传递给当前应用，个别组合可能冲突。改变系统权限需要用户在系统设置中自行授权。

构建：在本目录运行 `./script/build_and_run.sh --build-only`，带界面启动运行 `./script/build_and_run.sh`。需安装 Xcode 和 macOS 14 或更高版本。

界面语言目前只覆盖主要设置项的简体中文和英文，状态信息和部分选项暂时仍是中文。登录启动需要应用放在稳定位置，并由系统接受该应用的注册；临时签名应用的授权和注册在重建或移动后可能需要重新确认。
